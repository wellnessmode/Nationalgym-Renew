## Part 1. 왜 이 시스템이 필요한가

### 그동안의 문제

내셔널짐은 PT·골프 회원과 **재계약**이 잦습니다. 그런데 종이 계약서·구두 안내 방식에는 다음 문제가 반복됐습니다.

| 문제 | 실제로 벌어진 일 |
|---|---|
| **약관 변경 고지 누락** | 약관이 바뀌었는데 회원에게 변경 내용을 안 알리고 예전 안내만 함 |
| **서명 누락** | 바쁜 시간에 결제만 받고 서명을 못 받음 → 분쟁 시 증빙 없음 |
| **"그런 말 못 들었다" 분쟁** | 환불·양도 규정을 설명했다는 기록이 없음 |
| **종이 분실** | 계약서 원본이 어디 있는지 모름, 지점 이동 시 누락 |
| **환불 분쟁** | 위약금·카드수수료·공제 기준을 회원이 "동의한 적 없다"고 주장 |

### 이 시스템이 해결하는 것

- 회원이 **약관을 끝까지 확인**해야만 동의가 가능 → "못 봤다" 차단
- **본인확인 + 동의 시점·기기·IP가 자동 기록** → "내가 한 적 없다" 차단
- 모든 계약서가 **서버에 영구 보관** → 분실 없음, 어느 지점에서나 조회
- 환불·양도 규정에 **명시적으로 동의** → 환불 분쟁 시 강력한 증빙
- 회원은 **카카오톡 링크 하나**로 1분 만에 완료 → 데스크 업무 감소

> **한 줄 요약**: 분쟁이 생겼을 때 "회원이 직접, 약관을 다 보고, 동의했다"는 것을 법적으로 증명할 수 있게 해주는 시스템입니다.

## Part 2. 어떤 시스템인가

### 정의

회원에게 **카카오톡으로 계약서 링크를 보내면**, 회원이 휴대폰에서 **본인확인 → 약관 확인 → 동의 체크**만 하면 계약이 체결되는 전자계약 시스템입니다. 손글씨 서명을 받지 않아도 됩니다.

### 핵심 특징

- 📱 **모바일 전용 설계** — 회원 대부분이 휴대폰에서 진행
- ✍️ **체크박스 = 서명** — 「전자서명법」상 손글씨 서명과 동일한 효력
- 🔒 **자동 기록** — 접속 IP·기기·시간·약관 버전이 자동 저장
- 🏢 **지점별 사업자 자동 반영** — 용산 1호점·서초 2호점·피티앤골프 3호점 각각의 사업자 정보가 계약서에 정확히 들어감
- 📄 **PDF + 인증서 자동 생성** — 완료 즉시 계약서를 PDF로 저장 가능

### 등장 인물

| 구분 | 역할 |
|---|---|
| **관리자(직원)** | 계약 내용 입력 → 링크 생성 → 카카오톡 발송 → 상태 확인 |
| **회원** | 링크 클릭 → 본인확인 → 약관 확인 → 동의 |
| **시스템** | 모든 과정을 자동 기록·보관, 분쟁 시 증빙 제공 |

### 페이지 구성

| 페이지 | 용도 | 누가 쓰나 |
|---|---|---|
| `admin.html` | 계약서 발송 | 직원 |
| `list.html` | 계약 목록·상태 추적 | 직원 |
| `sign.html` | 약관 확인·동의 | 회원 (링크로만 접속) |
| `view.html` | 완료된 계약서 보기·PDF | 직원 + 회원 |

```
 ┌─────────────────────── 직원(데스크) ───────────────────────┐
 │                                                            │

 │  2. 약관 종류(PT/골프/통합) + 지점 선택                       │
 │  3. 회원 정보 입력                                          │
 │       이름 · 휴대폰 · 생년월일(필수!) · 항목 · 금액            │
 │  4. [서명 링크 생성] 클릭                                    │
 │  5. 자동 생성된 카카오톡 메시지 복사                          │
 │                                                            │
 └────────────────────────────┬───────────────────────────────┘
                              │ 카카오톡으로 발송
                              ▼

 │  6. 링크 클릭 → 안내 화면                                    │

 │  9. 동의 항목 체크 (필수 항목 전체)                          │
 │ 10. [동의·서명 제출]                                        │
 │                                                            │
 └────────────────────────────┬───────────────────────────────┘
                              │ 자동 저장 + 상태 갱신
                              ▼
 ┌─────────────────────── 직원(데스크) ───────────────────────┐
 │                                                            │
 │ 11. list.html 에서 '동의완료' 확인                          │

 │                                                            │
 └────────────────────────────────────────────────────────────┘
```

**상태는 실시간으로 자동 갱신됩니다:**

```
발송 → 열람 → 본인확인 → 동의완료
(sent) (viewed) (identified) (signed)
```

직원은 list.html 에서 회원이 지금 어느 단계인지 바로 볼 수 있습니다.

## Part 4. 관리자(직원) 사용법 — 단계별

### ① 로그인

1. https://wellnessmode.github.io/Nationalgym-Renew/admin.html 접속
2. 관리자 이메일·비밀번호 입력 (계정은 관리자에게 문의)
3. 로그인은 한 번 하면 유지됩니다. **공용 PC에서는 사용 후 [로그아웃]** 하세요.

### ② 약관 종류 & 지점 선택

| 약관 종류 | 사용 시점 |
|---|---|
| **PT + 골프 통합** | PT와 골프를 함께 등록하는 회원 |
| **PT 단독** | PT만 등록 |
| **골프 단독** | 골프만 등록 |

- 지점은 **반드시 정확하게** 선택하세요. 지점에 따라 계약서에 찍히는 **사업자등록번호가 다릅니다.**
  - 용산 1호점 → 188-62-00405
  - 서초 2호점 → 598-67-00456
  - 피티앤골프 3호점 → 297-09-02814
- 화면에 "✓ 활성 약관: ... v2026-06-22" (PT는 공통 약관) 이 보이면 정상입니다.

### ③ 회원 정보 입력

| 항목 | 필수 | 주의사항 |
|---|---|---|
| 이름 | ✅ | 회원이 본인확인 때 **똑같이** 입력해야 함. 띄어쓰기·오타 주의 |
| 휴대폰 | ✅ | 카카오톡 받는 번호. 끝 4자리가 본인확인에 쓰임 |
| **생년월일** | ✅ | **본인확인 필수 항목.** 비우면 회원이 진행 불가! |
| 이메일 | 선택 | |
| 주소 | 선택 | |
| 계약 항목 | ✅ | [+ 항목 추가]로 여러 개 입력 (예: "PT 30회 / 4개월") |
| 총 결제금액 | ✅ | 항목 금액 합계가 자동 계산됨 (수정 가능) |
| 결제수단 | | 카드/현금/서울페이/계좌이체/기타 |
| 이용 기간 | 선택 | |
| 사물함 | 선택 | |

> ⚠️ **가장 흔한 실수: 생년월일 누락.**
> 생년월일을 안 넣으면 회원이 본인확인 단계에서 막혀서 진행을 못 합니다. 꼭 입력하세요.

### ④ 링크 생성 & 카카오톡 발송

1. **[🔗 서명 링크 생성]** 클릭
2. 아래에 **카카오톡 발송 메시지**가 자동으로 만들어집니다. 이 메시지에는:
   - 계약 항목·금액
   - **본인확인 정보**(이름·생년월일·휴대폰 끝 4자리)
   - 서명 링크
   - 유효기간 안내
   가 모두 포함되어 있습니다.
3. **[메시지 복사]** 클릭 → 회원 카카오톡 채팅에 **붙여넣기**하여 발송
4. 링크 유효기간은 기본 **7일**입니다. 필요 시 발송 전에 조정하세요.

> 💡 메시지를 손대지 말고 **그대로** 보내세요. 본인확인 정보가 빠지면 회원이 헷갈립니다.

### ⑤ 상태 추적

**[📋 계약 목록]**(list.html)에서 확인합니다.

- 상단 **KPI 카드**: 전체 / 대기중 / 완료 / 만료 건수가 한눈에. 카드를 누르면 그 상태만 필터됩니다.
- **검색**: 이름·휴대폰으로 검색
- **필터**: 상태 · 지점 · 기간(오늘/이번주/이번달)
- 만료 임박 건은 **빨간 D-day 배지**로 표시됩니다.
- **[📥 CSV]**: 목록을 엑셀로 내보내기 (월말 정산·보고용)

상태가 **'동의완료(signed)'** 가 되면 계약 체결 완료입니다.

### ⑥ 완료된 계약서 보기 / PDF 저장

1. 목록에서 동의완료 건의 **[📄 보기]** 클릭
2. view.html 에서:
   - 계약 내용 + 약관 전문(동의 시점 박제본)
   - **전자서명 인증서**(접속 IP·기기·시간·무결성 해시·QR코드)
   - **감사 추적 로그**(직원에게만 보임)
3. **[📄 PDF 저장]** 으로 PDF 다운로드 → 회계·법무 보관용

### ⑦ 이중 보관 — 전체 백업 (월 1회)

1. 계약 목록 화면 우측 **[💾 전체 백업 (PC 저장)]** 클릭
2. 모든 계약(약관 보존본·동의 결과·감사 기록 포함)이 **HTML 파일 하나**로 다운로드됨
3. 이 파일은 **인터넷 없이** 더블클릭으로 열려 검색·열람·인쇄 가능 — 서버 장애 시 비상용 사본
4. 지정된 사무실 PC 폴더 또는 USB 에 보관. 버튼 옆에 마지막 백업 날짜 표시 (30일 경과 시 경고)

> ⚠️ 백업 파일에는 회원 개인정보가 포함됩니다. 카톡·메일로 외부 전송 금지, 안전한 곳에만 보관.

## Part 5. 회원은 무엇을 보게 되는가

직원이 회원의 화면을 이해하고 있어야 전화로도 도와줄 수 있습니다. 회원 화면은 **5단계**입니다.

| 단계 | 회원이 하는 일 | 직원이 알아둘 점 |
|---|---|---|
| **1. 안내** | [시작하기] 버튼 | 지점 상호·문의처가 표시됨 |
| **2. 본인확인** | 이름·생년월일·휴대폰 끝 4자리 입력 | 발송 시 입력한 정보와 **정확히** 일치해야 통과. 5회 틀리면 5분 잠김 |
| **3. 약관·내용 확인** | 약관을 **끝까지 스크롤** | 끝까지 안 내리면 다음 버튼이 안 켜짐 (의도된 동작) |
| **4. 동의** | 필수 항목 체크 | [필수 항목 모두 동의] 버튼 제공 (마케팅 등 선택 항목은 개별 선택). 필수 다 체크해야 제출 버튼 활성화 |
| **5. 완료** | 계약서 PDF 확인 | 계약서 보기·"카카오톡으로 받기" 가능 (해시·IP 등 검증 정보는 관리자 화면에만 표시) |

**동의 항목은 5개 그룹**으로 나뉩니다 (법적으로 분리 동의가 필요):

1. ① 계약 약관 (필수)
2. ② 개인정보 수집·이용 / 제3자 제공 (필수)
3. ③ 민감정보 = 건강상태 (필수)
4. ④ 시설 이용 안내 (골프 타석 단독이용 등)
5. ⑤ 마케팅 (선택 — 거부해도 계약됨)

## Part 6. 회원 문의 응대 가이드

회원이 자주 묻는 질문과 **그대로 읽어도 되는 답변**입니다.

### "이거 그냥 체크만 하는 건데 효력 있어요?"

> "네, 「전자서명법」에 따라 체크박스 동의도 손으로 쓴 서명과 똑같은 법적 효력이 있습니다. 오히려 종이보다 더 정확하게 기록이 남습니다. 동의하신 시간·기기 정보까지 자동으로 보관돼요."

### "왜 생년월일이랑 전화 뒷자리를 또 입력해요?"

> "본인 확인을 위한 절차예요. 다른 사람이 회원님 대신 동의하는 것을 막기 위한 거라, 회원님을 보호하는 장치입니다. 1분도 안 걸려요."

### "약관이 안 넘어가요 / 동의 버튼이 안 눌려요"

> "약관을 **맨 아래까지** 한 번 내려주세요. 끝까지 확인하셔야 다음으로 넘어가도록 되어 있어요. 다 내리시면 버튼이 켜집니다."

### "링크가 안 열려요 / 만료됐대요"

> "링크는 보내드린 후 7일간만 유효해요. 제가 새 링크를 다시 보내드릴게요." → admin.html 에서 **재발송**(새 계약 생성)

### 환불 문의

내셔널짐 환불 규정(약관 §3·§4 기준)을 정확히 안내하세요.

> **환불 공제금액 = 결제금액 − 위약금 10% − 카드 수수료 5% − 사은품/서비스 공제**
> - PT·레슨: 이미 이용한 **1회 정상가 × 이용 횟수** 공제
> - 골프 타석: 등록일~해지일 **날짜 × 35,000원** 공제
> - 사물함 비용은 환불 시 공제되지 않음(돌려주지 않음)

회원이 "동의 안 했다"고 하면 → view.html 에서 **동의 결과·시간** 보여주면 됩니다.

### 양도 문의

> - 잔여기간 **30일 이상**일 때만, **1회**, 양도수수료 **5만원**
> - 1회 양도 후에는 환불·재양도·휴회 모두 불가
> - 센터는 양도 대상을 주선·소개하지 않음

## Part 7. 왜 법적 효력이 있는가

직원이 자신감을 갖고 회원에게 설명할 수 있도록, 근거 법령을 정리합니다.

| 법령 | 이 시스템에서의 의미 |
|---|---|
| **전자서명법 §3** | 체크박스 동의 = 서명과 동일 효력 (2020년 법 개정으로 공인인증서 없이도 인정) |
| **전자문서법 §4** | 전자계약서가 종이 계약서와 동일한 효력 |
| **개인정보보호법** | 동의를 항목별로 분리(수집/제3자/민감/마케팅)했기 때문에 적법 |
| **전자상거래법 §6** | 계약 기록을 **5년간 보관** (자동) |
| **방문판매법 §31** | 헬스장은 "계속거래"라 회원이 중도해지 가능 — 약관에 안내됨 |
| **체력단련장 표준약관(공정위 제10095호)** | 위약금·환불 기준이 공정위 표준을 따름 |

**분쟁 시 우리가 제시할 수 있는 증거:**
- 회원 본인확인 통과 기록 (이름+생년월일+전화)
- 약관을 끝까지 확인한 기록
- 동의한 정확한 시각·IP·기기
- 동의 시점의 약관 전문(박제본)
- 위변조 방지 무결성 해시(SHA-256)

> 이 모든 것이 자동으로 남기 때문에, 종이 계약서보다 **분쟁에 훨씬 강합니다.**

## Part 8. 문제 해결(트러블슈팅)

| 증상 | 원인 | 해결 |
|---|---|---|
| 회원이 본인확인에서 계속 실패 | 발송 시 정보와 불일치 (이름 띄어쓰기, 생년월일 오타) | list.html 에서 발송 정보 확인 → 틀렸으면 **새로 발송** |
| 회원이 "생년월일 입력칸에서 막힘" | 발송 때 생년월일을 안 넣음 | 새 계약 생성 시 생년월일 입력 |
| "동의 버튼이 안 눌려요" | 약관 끝까지 안 내림 / 필수 항목 미체크 | 약관 끝까지 스크롤, 필수 항목 전체 체크 안내 |
| "링크 만료" | 7일 경과 | 새 링크 재발송 |
| "이미 서명한 계약입니다" 화면 | 이미 완료된 건을 다시 열음 | 정상. [계약서 보기]로 확인 가능 |
| 본인확인 5회 실패 후 잠김 | 보안 잠금 | **5분 후** 재시도 |
| 관리자 로그인이 안 됨 | 계정 문제 | 시스템 관리자에게 문의 |
| 약관 내용이 옛날 버전 | DB 미갱신 | 시스템 관리자에게 문의 (약관 업데이트 필요) |

> 위로 해결 안 되는 기술 문제는 **시스템 관리자**에게 전달하세요. 회원에게는 "확인 후 다시 연락드리겠다"고 안내하고 절대 추측으로 답하지 마세요.

## Part 9. 운영 수칙 & 체크리스트

### 발송 전 체크리스트

- [ ] 약관 종류가 맞는가? (PT / 골프 / 통합)
- [ ] **지점**이 맞는가? (사업자번호가 달라짐)
- [ ] 이름을 회원이 입력할 형태로 정확히 적었는가?
- [ ] **생년월일을 입력했는가?** ← 가장 중요
- [ ] 휴대폰 번호가 카카오톡 받는 번호와 같은가?
- [ ] 계약 항목·금액이 결제 내역과 일치하는가?

### 발송 후

- [ ] 카카오톡 메시지를 **수정 없이** 그대로 보냈는가?
- [ ] 회원에게 "약관 끝까지 내려야 동의 가능"하다고 한 마디 안내했는가?

### 완료 후

- [ ] list.html 에서 '동의완료' 확인
- [ ] (고액·분쟁 우려 건) view.html 에서 PDF 저장·보관

### 절대 하지 말 것

- ❌ 회원 대신 직원이 본인확인·동의를 입력 (효력 무효, 분쟁 시 치명적)
- ❌ 공용 PC에서 로그아웃 안 하고 자리 비우기
- ❌ 회원 개인정보(생년월일·연락처)를 외부로 유출
- ❌ 기술 문제를 추측으로 회원에게 답변

### 보안·개인정보

- 이 시스템의 모든 개인정보는 **법정 기간(5년) 보관 후 안전 파기**됩니다.
- 회원이 "내 정보 보여달라/지워달라"고 하면 → 시스템 관리자에게 전달 (열람·정정·삭제권 처리).
