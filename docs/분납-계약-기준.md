# 분납(2회) 계약 작성 기준

- **작성** 2026-09-17 · 매니저 「PT 계약서 검토 정리」 중 **§1 분납만 채택** — 환불조항 개정·패밀리세션 특약·케이스별 비고 등 나머지는 대표 지시로 제외
- **구성** ① 약관에 상시 들어가는 조항 1개(**제5조**) + ② 분납 계약일 때만 비고란에 붙는 블록 1개(**admin 자동 기재**)

## 1. 원칙 (직원)

| # | 원칙 | 이유 |
|---|---|---|
| 1 | **첫 결제 시점에 총액 기준 계약서 1건**을 보낸다 | 금액을 쪼개 2건 보내면 "내 단가는 15회 단가"라는 분쟁 근거를 센터가 만들어 주고, 완납 후 보내면 계속거래 계약서 교부 의무 위반 + 그 사이 사고·환불 요구 시 근거 문서 없음 |
| 2 | **분납은 2회까지** | 3회 이상은 할부거래법상 할부계약(2개월↑·3회↑) → 별도 규정. 3회 이상 원하면 **카드 할부**로 안내(센터는 전액 일시 입금, 미수금 0) |
| 3 | 2차 납입 예정일은 admin 에 입력해 비고란에 남기고 캘린더에 리마인드 | 미납 독촉 근거 |
| 4 | 2차 미납 시 잔여 회차 진행 보류 가능 — 근거는 **약관 제5조** | 비고에 다시 쓰지 않음(중복·모순 방지) |
| 5 | 중도해지 환급은 약관 환불 규정대로. **비고란에 별도 정산식을 적지 않는다** | 정산식이 둘이면 개별약정 우선·작성자 불이익 원칙으로 회원에게 유리한 쪽이 적용됨 |

## 2. 약관 제5조 — 전 약관 공통 상시 조항 (v2026-09-17)

> **5. 분납(분할 납입)**
> - 계약금액을 나누어 납입하는 경우에도 본 계약은 계약서에 기재된 **총 계약금액과 전체 회차**를 기준으로 성립하며, 납입 회차·금액·납입(예정)일은 본 계약서 비고란에 기재합니다.
> - 납입 예정일까지 해당 회차의 납입이 이루어지지 않은 경우, 센터는 납입이 완료될 때까지 **잔여 회차의 진행을 보류**할 수 있습니다.
> - 분납 여부와 관계없이 중도 해지 시의 환급은 본 계약서의 환불 규정(제3조)에 따릅니다.

적용 범위: PT 공통 · PT 서초 2호점 · PT+골프 통합(combo) · 골프 — 4종 모두 신규 버전 `2026-09-21`(서초 `2026-09-21-seocho`)로 추가, 구버전 비활성. 기서명 계약은 template_id 스냅샷으로 영향 없음.

## 2-1. 약관 제6조 — 패밀리세션 (PT 약관에만, 2026-09-21 추가)

매니저 요청으로 함께 반영. **PT 공통·PT 서초에만** 들어가고 combo·golf 에는 없음(패밀리세션은 PT 회차 상품 전용).

> **6. 패밀리세션(2인 합산 50회) 특약**
> - 두 분이 각자 본인 명의로 **최소 10회 이상 이용**하는 조건의 할인 단가. 개인 단독 등록엔 미적용
> - **계약 명의자 본인만** 수강. 대리 수강 회차는 미인정
> - 한 분이 **30회 도달 시 상대가 10회 미달**이면, 상대가 10회를 채울 때까지 30회 초과분 진행 보류
> - 조건이 끝내 미충족이면(이용 의사 없음 통지·유효기간 만료) **이용한 회차를 개인 30회권 기준 회당 단가로 계산하고 잔액은 현금 환불**. 추가 청구·추가 회차 부여 없음
> - 회차 이전은 **양측 모두 10회 이상 진행 후**에만 가능

정산식 근거(센터 무손실·계산 단순·회원 불만 없음)와 수치 검증은 `docs/PT-패밀리세션-분납-계약검토.md` 참조.
별도 동의 체크박스는 두지 않음 — 약관 전문 100% 스크롤 + '약관 전문 동의'로 커버되고, 패밀리가 아닌 대다수 PT 회원에게 불필요한 항목이 노출되면 반감만 커짐.

## 3. 비고란 블록 — 분납일 때만 (admin 자동 기재)

```
[분납] 총 결제금액 2,310,000원을 2회 분납 — 1차 1,155,000원(2026.09.17 납입) / 2차 1,155,000원(2026.10.17 납입 예정). 분납 관련 사항은 약관 제5조에 따름.
```
- 총액을 명시해 "계약 = 총액"을 비고에서도 못 박고, **일정만** 적는다. 보류·환급 기준은 제5조가 담당.
- 회원 서명화면·완료본의 "비고" 행에 그대로 표시·박제된다. 직원이 따로 쓴 비고(사은품 등)는 그 뒤에 보존.

## 4. admin 사용법

1. 「3. 계약 항목」에서 항목·총 결제금액 입력
2. **☑ 분납 계약 (2회)** 체크 → 1차/2차 금액(50/50 자동 제안, 수정 가능) · 1차 납입일(오늘 자동) · 2차 납입 예정일 입력
3. 「서명 링크 생성」 → **1차+2차 ≠ 총액**이거나 **2차일 ≤ 1차일**이면 발송 차단(오류 문구 표시)
4. 통과 시 비고란 맨 앞에 위 블록이 자동 기재되고, 카톡 발송문에도 `분납: 1차 … / 2차 …(납입 예정)` 한 줄이 들어감
