1. 왜 이 시스템이 필요한가

그동안의 문제

내셔널짐은 PT·골프 회원과 재계약이 잦습니다. 종이 계약서·구두 안내 방식에는 다음 문제가 반복됐습니다.

문제실제로 벌어진 일
약관 변경 고지 누락약관이 바뀌었는데 변경 내용을 안 알리고 예전 안내만 함
서명 누락바쁜 시간에 결제만 받고 서명을 못 받음 → 분쟁 시 증빙 없음
"그런 말 못 들었다" 분쟁환불·양도 규정을 설명했다는 기록이 없음
종이 분실원본이 어디 있는지 모름, 지점 이동 시 누락
환불 분쟁위약금·카드수수료·공제 기준에 "동의한 적 없다"고 주장

이 시스템이 해결하는 것

  • 회원이 약관을 끝까지 확인해야만 동의 가능 → "못 봤다" 차단
  • 본인확인 + 동의 시점·기기·IP 자동 기록 → "내가 한 적 없다" 차단
  • 모든 계약서 서버 영구 보관 → 분실 없음, 어느 지점에서나 조회
  • 환불·양도 규정에 명시적 동의 → 환불 분쟁 시 강력한 증빙
  • 회원은 카카오톡 링크 하나로 1분 만에 완료 → 데스크 업무 감소

2. 어떤 시스템인가

회원에게 카카오톡으로 계약서 링크를 보내면, 회원이 휴대폰에서 본인확인 → 약관 확인 → 동의 체크만 하면 계약이 체결되는 전자계약 시스템입니다. 손글씨 서명을 받지 않아도 됩니다.

핵심 특징

  • 📱 모바일 전용 설계 — 회원 대부분이 휴대폰에서 진행
  • ✍️ 체크박스 = 서명 — 「전자서명법」상 손글씨 서명과 동일 효력
  • 🔒 자동 기록 — 접속 IP·기기·시간·약관 버전 자동 저장
  • 🏢 지점별 사업자 자동 반영 — 용산점·서초점·골프스튜디오 각각의 사업자 정보가 정확히 들어감
  • 📄 PDF + 인증서 자동 생성

5. 회원은 무엇을 보게 되는가

직원이 회원 화면을 이해하고 있어야 전화로도 도울 수 있습니다. 회원 화면은 5단계입니다.

단계회원이 하는 일직원이 알아둘 점
1. 안내[시작하기]지점 상호·문의처 표시
2. 본인확인이름·생년월일·휴대폰 끝 4자리발송 정보와 정확히 일치해야 통과. 5회 틀리면 5분 잠김
3. 약관 확인약관 끝까지 스크롤끝까지 안 내리면 다음 버튼이 안 켜짐 (의도된 동작)
4. 동의필수 항목 체크[필수 항목 모두 동의] 제공 (마케팅 등 선택 항목은 개별 선택). 필수 다 체크해야 제출 활성화
5. 완료계약서 PDF 확인계약서 보기·"카카오톡으로 받기" 가능 (해시·IP 등 검증 정보는 관리자 화면에만 표시)

동의 항목은 5개 그룹으로 분리됩니다(법적으로 분리 동의 필요):

  1. ① 계약 약관 필수
  2. ② 개인정보 수집·이용 / 제3자 제공 필수
  3. ③ 민감정보 = 건강상태 필수
  4. ④ 시설 이용 안내 (골프 타석 단독이용 등)
  5. ⑤ 마케팅 선택 — 거부해도 계약됨

6. 회원 문의 응대 가이드

아래 회색 박스는 그대로 읽어도 되는 답변입니다.

"이거 그냥 체크만 하는 건데 효력 있어요?"

"네, 「전자서명법」에 따라 체크박스 동의도 손으로 쓴 서명과 똑같은 법적 효력이 있습니다. 오히려 종이보다 더 정확하게 기록이 남습니다. 동의하신 시간·기기 정보까지 자동으로 보관돼요."

"왜 생년월일이랑 전화 뒷자리를 또 입력해요?"

"본인 확인을 위한 절차예요. 다른 사람이 회원님 대신 동의하는 것을 막기 위한 거라, 회원님을 보호하는 장치입니다. 1분도 안 걸려요."

"약관이 안 넘어가요 / 동의 버튼이 안 눌려요"

"약관을 맨 아래까지 한 번 내려주세요. 끝까지 확인하셔야 다음으로 넘어가도록 되어 있어요. 다 내리시면 버튼이 켜집니다."

"링크가 안 열려요 / 만료됐대요"

"링크는 보내드린 후 7일간만 유효해요. 제가 새 링크를 다시 보내드릴게요."

→ admin.html 에서 재발송(새 계약 생성)

환불 문의

환불 공제금액 = 결제금액 − 위약금 10% − 카드 수수료 5% − 사은품/서비스 공제
  • PT·레슨: 이용한 1회 정상가 × 이용 횟수 공제
  • 골프 타석: 등록일~해지일 날짜 × 35,000원 공제
  • 사물함 비용은 환불 시 공제되지 않음(돌려주지 않음)

회원이 "동의 안 했다"고 하면 → view.html 에서 동의 결과·시간을 보여주면 됩니다.

양도 문의

  • 잔여기간 30일 이상일 때만, 1회, 양도수수료 5만원
  • 1회 양도 후 환불·재양도·휴회 모두 불가
  • 센터는 양도 대상을 주선·소개하지 않음

7. 왜 법적 효력이 있는가

법령이 시스템에서의 의미
전자서명법 §3체크박스 동의 = 서명과 동일 효력 (2020년 개정으로 공인인증서 없이 인정)
전자문서법 §4전자계약서가 종이와 동일한 효력
개인정보보호법동의를 항목별 분리(수집/제3자/민감/마케팅)해 적법
전자상거래법 §6계약 기록 5년 자동 보관
방문판매법 §31헬스장은 "계속거래" — 중도해지 가능, 약관에 안내됨
체력단련장 표준약관(공정위 제10095호)위약금·환불 기준이 공정위 표준을 따름
분쟁 시 제시 가능한 증거: 본인확인 통과 기록 · 약관 끝까지 확인 기록 · 동의 시각/IP/기기 · 동의 시점 약관 전문(박제) · 위변조 방지 해시(SHA-256). 종이 계약서보다 분쟁에 훨씬 강합니다.

8. 문제 해결(트러블슈팅)

증상원인해결
본인확인 계속 실패발송 정보와 불일치(이름 띄어쓰기·생년월일 오타)list.html 에서 발송 정보 확인 → 틀렸으면 새로 발송
생년월일 칸에서 막힘발송 때 생년월일 누락새 계약 생성 시 생년월일 입력
동의 버튼 안 눌림약관 끝까지 안 내림 / 필수 미체크끝까지 스크롤, 필수 전체 체크 안내
링크 만료7일 경과새 링크 재발송
"이미 서명한 계약" 화면완료 건 재방문정상. [계약서 보기]로 확인
5회 실패 후 잠김보안 잠금5분 후 재시도
관리자 로그인 안 됨계정 문제시스템 관리자 문의
약관이 옛날 버전DB 미갱신시스템 관리자 문의
해결 안 되는 기술 문제는 시스템 관리자에게 전달. 회원에게는 "확인 후 다시 연락드리겠다"고 안내하고 추측으로 답하지 마세요.

9. 운영 수칙 & 체크리스트

발송 전 체크리스트

  • 약관 종류가 맞는가? (PT / 골프 / 통합)
  • 지점이 맞는가? (사업자번호가 달라짐)
  • 이름을 회원이 입력할 형태로 정확히 적었는가?
  • 생년월일을 입력했는가? ← 가장 중요
  • 휴대폰 번호가 카카오톡 받는 번호와 같은가?
  • 계약 항목·금액이 결제 내역과 일치하는가?

발송 후 / 완료 후

  • 카카오톡 메시지를 수정 없이 그대로 보냈는가?
  • "약관 끝까지 내려야 동의 가능" 한 마디 안내했는가?
  • list.html 에서 '동의완료' 확인했는가?
  • (고액·분쟁 우려 건) view.html 에서 PDF 저장했는가?

절대 하지 말 것

  • 회원 대신 직원이 본인확인·동의 입력 (효력 무효, 분쟁 시 치명적)
  • 공용 PC에서 로그아웃 안 하고 자리 비우기
  • 회원 개인정보(생년월일·연락처) 외부 유출
